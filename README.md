# Aksa Fathima — personal academic website

Static site (no build step). Layout follows the al-folio academic theme.

## Publish on GitHub Pages
1. Create a repo named `<your-username>.github.io`.
2. Upload everything in this folder (keep the `assets/` folder).
3. Settings → Pages → Source: `main` branch, `/ (root)`.

## Edit
- All text lives in `index.html` (one `<section data-view="...">` per page).
- Profile photo: add `assets/img/profile.jpg` (square, ~600×600). It replaces the AF monogram automatically.
- CV: replace `assets/docs/Aksa_Fathima_CV.pdf`.
- Pages are reached by hash links: `#about`, `#projects`, `#publications`, `#cv`, `#gallery`, `#contact`,
  and project pages `#oscc`, `#lymph-node`, `#ammonia`, `#chf`, `#nanofiber`.
